# 题目逐项对照

| 原题要求               | 实现位置 / 可观察行为                                         | 当前边界                                                             |
| ---------------------- | ------------------------------------------------------------- | -------------------------------------------------------------------- |
| 完整免登录工作台       | 匿名 Cookie + D1 支持全部研究、历史与记忆；服务端执行，可清空 | 无需任何账号；不同浏览器隔离，更换设备或删除 Cookie 无法恢复原工作台 |
| 用户给出研究目标       | 自由文本 → 意图/日期/标的 → 不同工具计划；信息不足时澄清      | 无模型时明确规则降级；能力范围为 A 股/指数行情及公司财务/估值        |
| 能力/工具注册          | `tools.ts` 注册 7 项能力、参数、权限、时延和调用成本          | iFinD 未接入                                                         |
| 计划执行               | `engine.ts` 服务端逐步推进，模型计划校验后执行                | 页面关闭后不持续调度新步骤                                           |
| 上下文压缩             | 16,000 字符阈值/手动压缩，摘要与增量证据用于模型解释          | 使用确定性摘要；非复杂 RAG                                           |
| 长期记忆               | D1 保存主动填写偏好，新研究读取，可删除                       | 已创建线程保留快照以便复现                                           |
| 检查点与恢复           | 每步状态落库，URL恢复线程，成功结果复用                       | 在途只读请求可能重试，不承诺外部 exactly-once                        |
| 权限、审批             | 匿名凭据 + 所有权检查；范围/额度审批绑定计划版本              | 所有金融工具均为只读                                                 |
| 停止、成本、时延       | 请求前检查，有限重试，调用/token/时间上限                     | 无供应商账单，费用显示未计价，token可能估算                          |
| 可观测性               | 真实事件、参数摘要、耗时、错误、用量、压缩与恢复记录          | 不展示模型隐藏推理                                                   |
| 线程、任务、证据、产物 | 工作台历史、任务列表、证据抽屉、图表和报告导出                | 单研究对应一个持久化 run                                             |
| 动态 UI                | 审批、澄清、失败重试、图表、报告随运行状态出现                | 不采用计时器伪造工具结果                                             |
| 模型/工具失败降级      | 模型规则降级、工具有限重试、缺失标记、部分报告                | 真实模式不会自动改成构造数据                                         |
| 核心结论可验证         | 来源、字段、时点、单位、口径、公式、输入证据                  | 不宣称已做多源交叉仲裁                                               |
| 金融输出边界           | 事实/推断/不确定分开，禁止交易工具和承诺输出                  | 文本过滤不是正式合规认证                                             |
| 密钥与隐私             | 共享服务端 secret、个人密钥仅内存、元数据白名单、工作台隔离   | 不保存真实持仓                                                       |
| 线上 URL / 源码        | Sites 托管流程与源码仓库；本地源文件可运行                    | 发布是否成功以最终交付消息为准                                       |
| README / AI记录 / 测试 | 本仓库对应文档与可执行测试                                    | 真实 Groq + 扶摇行情/财报/估值已验收；国产模型仅契约测试             |

本版本没有把“适配器已实现”“样本契约测试通过”写成“真实账户调用已完成”。验收应同时检查页面行为、数据库状态和原始证据。

共享模型为默认来源；访客可在“模型设置”配置自己的 DeepSeek、千问、GLM、Kimi、豆包、硅基流动、Groq/OpenRouter key 或选择规则来源，不需要 ChatGPT 账号。个人密钥不进入长期状态，共享调用有原子预留的全站与工作台额度。

产品仅创建真实数据研究。首页聚焦目标，确认计划后执行，结果先展示关键指标与少量主要发现；完整事实、任务、证据库、运行记录、预算和上下文收纳于折叠区。审批与数据缺口保持显式展示。
