## 运行方式

先启动本地应用：

```bash
npm ci
npm run db:local
npm run dev -- --host 127.0.0.1 --port 5173
```

另一个终端执行：

```bash
npm test
npm run test:workspace
npm run typecheck
npm run test:api
npx playwright install chromium
npm run test:ui
```

已有兼容 Chromium 时可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`。所有流程均使用免登录浏览器/匿名 Cookie，无平台模拟账号；创建的研究和偏好均为测试内容。不要将这些测试直接指向包含真实用户数据的生产账户。

## 核心测试覆盖

- 不同自由目标产生不同标的与工具计划；模型可选择受注册表约束的工具组合。
- 完整证券代码去重；近一月、三个月、明确日期范围与未知标的澄清。
- 长期偏好实际影响新计划，当前显式要求优先。
- 三年财务研究、合并口径、引用 ID 全部可解析。
- 服务端预算用尽后不再调用；错误/过期审批不可通过；拒绝后停止。
- 扩展研究范围需确认；部分报告不新增数据或模型调用。
- 检查点序列化后恢复，成功任务不重复执行。
- 工具失败与单任务重试；原有其他证据复用。
- 行情/财务字段缺失时保留 null，不补零、不生成相应衍生指标。
- 区间涨跌幅、最大回撤、年化波动可复算。
- 压缩实际缩短后续上下文，保留原始证据与关键口径。
- 时限、停止请求在服务端生效。
- 指数不能伪装成公司财报对象；模型不能选择非法工具、日期或范围外的证券。
- 扶摇 HTTP 200 中的业务错误仍视为失败。
- 财报披露日必须早于截止日，上海日界线不会纳入次日记录。
- 历史研究忽略同响应内的最新快照，避免时间穿越。
- 缺时点证据不能作为事实或进入模型推断。
- 模型 HTTP 错误或不合规解释透明降级。

模型相关测试通过 mock fetch 验证接口契约与错误分支，**不代表真实模型调用验收**。

## API 与浏览器覆盖

API 检查真实本地 D1：匿名工作台初始化与持久化、跨站写入拒绝、记忆读取/删除、审批门禁、暂停恢复、证据引用、压缩持久化、并发推进去重、跨工作台隔离、伪造平台身份无效、Cookie 校验、无需登录选择真实数据、清空与旧凭据撤销。

浏览器验证桌面完整任务与审批、打开证据详情、导出报告、刷新后恢复当前线程，保存/删除记忆，以及 390px 手机布局和导航无横向溢出。没有报告未实际执行的 Firefox/WebKit、原生 WebMCP 验证。

WebMCP 通过特性检测注册 `create_research`，不支持的浏览器保持正常 UI；当前测试环境未提供原生 WebMCP 上下文，因此该标准的原生互操作验证仍未完成。

## 完整免登录使用覆盖

- 3 项凭据测试：HTTPS Cookie 的 Secure/HttpOnly/Host/SameSite 属性、256 位随机数与哈希存储；拒绝重复或无效 Cookie；本地 HTTP 不依赖 ChatGPT 身份头。
- 5 项浏览器测试：研究计划、审批、证据、报告、刷新恢复；研究记忆保存/删除；手机布局；同一浏览器新标签页恢复研究与偏好、不同浏览器无法访问；清空工作台；真实模式开放；没有登录链接或登录请求；禁用草稿存储仍可完成研究。
- 旧的“只在浏览器中运行构造数据”的临时访客模块和对应测试已移除，所有研究统一使用匿名工作台和服务端执行器。
