## 运行方式

先启动本地应用：

```bash
npm ci
npm run db:local
npm run dev -- --host 127.0.0.1 --port 5173
```

另一个终端执行：

```bash
npm test
npm run test:guest
npm run typecheck
npm run test:api
npx playwright install chromium
npm run test:ui
```

已有兼容 Chromium 时可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`。账号流程使用开发环境模拟登录，访客流程使用无登录的新浏览器上下文；创建的研究和偏好均为测试内容。不要将这些测试直接指向包含真实用户数据的生产账户。

## 核心测试覆盖

- 不同自由目标产生不同标的与工具计划；模型可选择受注册表约束的工具组合。
- 完整证券代码去重；近一月、三个月、明确日期范围与未知标的澄清。
- 长期偏好实际影响新计划，当前显式要求优先。
- 三年财务研究、合并口径、引用 ID 全部可解析。
- 服务端预算用尽后不再调用；错误/过期审批不可通过；拒绝后停止。
- 扩展研究范围需确认；部分报告不新增数据或模型调用。
- 检查点序列化后恢复，成功任务不重复执行。
- 工具失败与单任务重试；原有其他证据复用。
- 行情/财务字段缺失时保留 null，不补零、不生成相应衍生指标。
- 区间涨跌幅、最大回撤、年化波动可复算。
- 压缩实际缩短后续上下文，保留原始证据与关键口径。
- 时限、停止请求在服务端生效。
- 指数不能伪装成公司财报对象；模型不能选择非法工具、日期或范围外的证券。
- 扶摇 HTTP 200 中的业务错误仍视为失败。
- 财报披露日必须早于截止日，上海日界线不会纳入次日记录。
- 历史研究忽略同响应内的最新快照，避免时间穿越。
- 缺时点证据不能作为事实或进入模型推断。
- 模型 HTTP 错误或不合规解释透明降级。

模型相关测试通过 mock fetch 验证接口契约与错误分支，**不代表真实模型调用验收**。

## API 与浏览器覆盖

API 检查真实本地 D1：认证、跨站写入拒绝、记忆读取/删除、审批门禁、暂停恢复、证据引用、压缩持久化、并发推进去重。

浏览器验证桌面完整任务与审批、打开证据详情、导出报告、刷新后恢复当前线程，保存/删除记忆，以及 390px 手机布局和导航无横向溢出。没有报告未实际执行的 Firefox/WebKit、生产平台身份或原生 WebMCP 验证。

WebMCP 通过特性检测注册 `create_research`，不支持的浏览器保持正常 UI；当前测试环境未提供原生 WebMCP 上下文，因此该标准的原生互操作验证仍未完成。

## 免登录体验覆盖

- 4 项执行/存储测试：完整构造研究中无任何外部 fetch、审批和刷新恢复；不同目标产生不同计划；拒绝真实模式/长期记忆/其他存储的研究；篡改模式或损坏的存储可清除恢复；配额错误保留原记录；并发操作串行提交。
- 新增 3 项浏览器测试：不登录完成自由目标、暂停恢复、预算审批、证据和导出；全过程无 POST；独立浏览器不能读取临时记录；390px 手机布局无横向溢出；登录后不会把访客记录写入个人空间；禁用存储不崩溃，损坏记录可清除恢复。
