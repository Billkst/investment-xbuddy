# 投资 XBuddy

面向个人投资研究者的 Agent 工作台。输入自由研究目标，系统识别标的、时间范围和研究重点，生成受工具能力约束的任务计划，逐步执行并保存证据，产出可以回查原始字段的研究备忘录。

本项目按 **3 小时实现预算**取舍，题目原文见 [docs/SPEC.md](docs/SPEC.md)。公司对比只是一个示例，入口支持自由目标；例如公司盈利质量、估值对比、个股行情或指数回撤研究会产生不同计划。

## 当前实际能力与限制

- 已实现模型规划、服务端执行器、7 项工具注册、上下文压缩、长期偏好、检查点、恢复、审批、暂停、预算控制与运行记录。
- **共享 Groq 模型与扶摇金融数据均已使用用户提供的真实凭据接通并验收**。扶摇行情快照、指数历史日线、年度利润表、年度现金流和估值接口返回业务成功；真实模型→真实数据→带引用报告的端到端链路已通过。
- 产品只提供真实数据研究。构造数据选择、故障演练及旧演示历史已从研究空间移除，API 同样拒绝新建或推进演示研究；旧记录未被转换为真实数据。纯引擎单元测试仍使用构造夹具。
- 个人密钥支持 DeepSeek、通义千问、智谱 GLM、Kimi、豆包、硅基流动，以及 Groq/OpenRouter。国产服务已按官方文档适配并验证请求契约，尚未使用各家的真实账户验收。
- **iFinD MCP 连接与工具发现已接通**，真实账户握手与 `tools/list` 返回 9 个工具。设置页可以验证连接并查看工具参数，结果保存在服务端；更换密钥会使旧验证失效。当前尚未将这些工具注册到研究执行器，因此现有报告仍由扶摇等来源产生。
- 已通过 29 项核心测试、3 项匿名凭据测试、6 项模型配置测试、16 项本地 API 验收与 6 项 Chromium 浏览器验收。网站公开且无需任何账号。

## 本地启动

需要 Node.js 24（测试使用原生 TypeScript 类型剥离）和 npm。

```bash
npm ci
npm run db:local
npm run dev -- --host 127.0.0.1 --port 5173
```

打开终端打印的本地地址即可使用全部已实现功能，不需要账号。浏览器自动取得本站生成的匿名工作台 Cookie，开发与生产均不依赖 ChatGPT 身份。**开发服务器不应直接暴露到公网。**

本地运行时，研究与记忆保存在 `.wrangler/state/` 的 SQLite/D1 中，刷新及重启开发服务后保留；部署后保存在站点的 D1 中。该目录与所有密钥文件均已忽略，不提交到源码仓库。

生产构建：

```bash
npm run typecheck
npm test
npm run build
```

部署使用项目内 `.openai/hosting.json` 指定的 Sites 项目及 D1 逻辑绑定。构建产物为 Cloudflare Workers 兼容服务端与静态资源，数据库迁移位于 `drizzle/`，由托管发布流程应用。`npm run start` 可运行生产构建。本站的研究功能不调用平台登录接口，本地完整交互验收使用开发服务。

## 环境变量

复制 `.env.example` 为 `.env`，仅在服务端配置。部署环境需通过托管平台的 secret/环境变量配置，不应把本地文件上传或将密钥传入浏览器。

| 变量                             | 用途                                                      | 未配置时                                |
| -------------------------------- | --------------------------------------------------------- | --------------------------------------- |
| `LLM_BASE_URL`                   | 服务商官方兼容接口根地址，不包含 `/chat/completions`      | 使用规则规划                            |
| `LLM_API_KEY`                    | 对应模型服务的 API 密钥                                   | 使用规则规划                            |
| `LLM_MODEL`                      | 该服务可调用的模型标识                                    | 使用规则规划                            |
| `FUYAO_API_KEY`                  | 扶摇 `X-api-key`                                          | 行情走公开备用源；真实财报/估值形成缺口 |
| `IFIND_MCP_API_KEY` | iFinD MCP 官网取得的独立密钥，服务端原样 Authorization | 设置页显示待配置 |
| `CONTEXT_LIMIT`                  | 触发上下文压缩的字符数，默认 `16000`；不是模型 token 窗口 | 使用默认阈值                            |
| `TEST_BASE_URL`                  | API/浏览器验收地址，默认本地 `5173`                       | 使用默认地址                            |
| `PLAYWRIGHT_CHROMIUM_EXECUTABLE` | 可选的本地 Chromium 可执行文件路径                        | 使用 Playwright 已安装浏览器            |

模型供应商需要支持 `messages`、`max_tokens` 和 `response_format: { type: "json_object" }`。不兼容、超时、HTTP 错误或结构校验失败时均会留下模型降级事件。共享模型使用维护者实际配置的账户，不继承开发助手的模型额度。

## 免登录工作台

打开公开页面即可输入研究目标，使用全部已实现功能：规划、研究执行、预算与范围确认、暂停恢复、上下文压缩、证据、报告导出以及长期研究偏好。所有新研究都使用真实金融接口；未配置或调用失败时明确报告缺口，不补造数据。

浏览器首次访问时由服务端生成 256 位随机 Cookie，服务端只保存其哈希。生产 Cookie 使用 `__Host-`、HttpOnly、Secure、SameSite=Lax，有效期一年；不采集账号、邮箱或 ChatGPT 身份。研究与记忆保存在独立的服务端工作台，同一浏览器再次打开或新建标签页可继续。更换浏览器、设备或删除 Cookie 后无法找回原工作台，重要报告请导出。

所有请求都验证匿名凭据及资源归属，复制研究 URL 不会赋予另一访客访问权。“清空工作台”会在确认后原子删除当前工作台的研究、检查点和记忆，撤销旧凭据并生成新工作台。最多保存 50 条研究和 20 条偏好。浏览器需要允许本站 Cookie；草稿使用的 sessionStorage 不可用时仍能完成服务端研究。此机制不提供跨设备账号同步或凭据找回。

此前平台账号空间和旧版临时存储中的数据没有被迁移或删除，当前界面不再读取这些旧身份；不是把过去的个人研究公开给所有人。

## AI 由什么驱动

默认使用站点服务端的 Groq 共享模型，负责理解个性化目标、选择受控工具与生成引用证据的解释。Harness 负责执行、审批、恢复与预算；金融数值由工具获取和确定性公式计算，不能由模型编造。接口失败时明确记录规则降级。

访客点击右上角“模型设置”→“使用我的 API key”，选择服务商、填写模型名与密钥，可先测试连接再应用。密钥仅保存在当前页面内存，刷新或关闭后需重新填写；调用时发给本站后端，再转交固定白名单内的服务商，研究目标和证据也会发送至该服务商。个人密钥不写入 D1、日志、导出报告、localStorage 或 sessionStorage；研究仅保存来源、服务商和模型名。已有个人模型研究在密钥丢失时提示重填，也可明确选择以规则继续。清除密钥不会自动启用共享调用。

共享 key 仅保存在服务端。默认站点保护额度为全站每天 40 次、每分钟 6 次、每工作台每天 8 次，以及每天 180,000 token 保守预留量；个人 key 使用独立额度桶，不占共享额度。每日按 UTC 切换。所有适用额度在同一数据库事务内预留，拒绝时整体回滚；已发起调用即使失败也保留预留。UTF-8 字节加输出上限用于保守预留，不等于账单；研究详情在供应商返回 usage 时显示实际 token。匿名用户可清 Cookie，因此工作台限制不能替代全站上限。参数见 `.env.example`。

Groq 免费额度取决于账户，且按组织共享，并非每个访客各获一份：[官方额度说明](https://console.groq.com/docs/rate-limits)。OpenRouter 默认个人模型是支持按能力路由的 `openrouter/free`：[官方模型页](https://openrouter.ai/openrouter/free/)。OpenRouter 适配尚未使用真实账户验收。免费服务不承诺无限或永久可用，超额会提示或明确降级；不会自动切换付费套餐。

`CONTEXT_LIMIT=16000` 仅决定何时将研究上下文压缩为摘要，原始证据始终保留。报告使用压缩摘要与增量证据，并补充已覆盖证据的来源、首末样本、数量、质量说明及计算输入，不发送完整逐日日线；初始规划只发送目标、偏好与工具能力。模型自身上下文窗口、站点配额和单轮 token 预算分别控制，不能把这个阈值理解为模型最多只能看 16,000 token。

## 产品使用与界面取舍

1. 输入研究目标，或选择真实行情/公司比较示例。
2. 确认标的、起止日期、研究重点与计划，点击“确认并开始研究”。
3. 查看执行进度；范围或额度不足时会请求批准，允许随时暂停。
4. 完成后直接查看关键指标和主要发现，点击指标或引用核验原始字段。完整事实默认折叠，可导出完整 Markdown 报告。
5. 展开“查看研究过程”访问全部任务、失败重试、执行事件、额度/token、证据库、检查点与上下文压缩。技术信息不会常驻首屏。
6. “研究记忆”保存个人偏好；“设置”配置模型、查看数据服务与工具边界。需要调整调用上限或清空工作台时，展开设置中的“研究额度与本地记录”。

界面按“提出问题→确认计划→阅读结果”排列。保持 Harness 机制可验证，同时把证据和结论置于主要阅读区域。审批与重要数据缺口仍然直接展示，不藏入技术记录。

## Harness 运行方式

```text
自由目标 + 已保存偏好
        ↓
模型结构化规划 / 明确标记的规则降级
        ↓
服务端验证工具、参数、标的范围、日期
        ↓
计划就绪 → 用户开始
        ↓
获取执行租约 → 检查预算、停止和审批
        ↓
执行一个步骤 → 保存证据、使用量、事件与检查点
        ↓
必要时压缩上下文 → 下一步 / 等待确认 / 暂停
        ↓
确定性指标计算 → 带引用的研究产物
```

- 模型可以选择注册的数据工具组合；执行器只接受白名单工具及研究范围内的证券参数，不能访问模型任意指定的 URL。
- 每个 `advance` 请求执行一个步骤。页面打开时继续推进，关闭页面后当前请求可能完成，但不会新建后续后台任务；重新打开线程即可继续。
- 执行租约防止同时推进同一任务。请求前保存执行状态和预算预留；终态写入及检查点追加在 D1 batch 中完成。
- 已提交成功的步骤恢复时复用。若外部调用已发生、最终结果尚未提交时进程中断，租约过期后只读请求可能重试；不宣称严格的外部 exactly-once。
- 暂停允许当前已发出的请求完成并保存结果；每次新外部请求前检查停止标记，包括有限重试。
- 最多 4 个标的，默认超过 2 个须确认；数据/模型调用额度默认 10、硬上限 40，单轮累计执行时限 4 分钟，模型 token 预算 48,000。费用未接入供应商账单，界面明确“未计价”，通过调用与 token 上限控制成本。模型未返回 usage 时保守预留的 token 为估算，不能当作账单。
- “生成部分报告”不增加外部请求，只根据已有证据计算和整理。
- 压缩保留目标、约束、证据 ID、单位、口径、质量说明、计算公式与输入引用；原始证据不删除。后续模型解释读取压缩上下文。
- 长期记忆只保存用户主动填写的偏好。删除后不用于新计划；已存在研究保留创建时的偏好快照，以便复现。

## 数据来源与统计口径

- [扶摇官方文档](https://fuyao.aicubes.cn/docs/) / [完整接口契约](https://fuyao.aicubes.cn/llms-full.txt)：服务端 `X-api-key`。除 HTTP 状态外必须检查业务 `code === 0`；实测无密钥即使 HTTP 200 也返回 `code=2003`。
- [iFinD MCP](https://mcp.51ifind.com/)：服务端以独立密钥完成初始化、工具发现和分页，支持 JSON/SSE 响应；仅接受官方固定端点。连接验证全站每分钟最多 6 次、每天 60 次，30 秒内复用验证结果，避免重复消耗账户请求。工具定义只用于展示，尚未执行 `tools/call` 或自动进入模型上下文。
- 腾讯财经公开网页行情接口：无需密钥的备用源，非稳定契约。股票取 `qfqday`，指数取 `day`；保留原始行与字段路径，不使用未经确认单位的成交量。
- 构造数据仅保留在引擎测试夹具中，产品 API 无法启用；公开仓库不保存真实账户返回的数据。

财报金额为人民币元，采用年度合并口径，现金利润比为经营现金流净额 / 同期合并净利润，不混用归母利润。报告期与披露日均须不晚于研究截止日；按上海时区判断日界线。估值和行情快照仅用于当前时点，不能代替历史快照。

历史价格在请求区间内过滤。指数单位为“点”，股票为“元/股”。前复权序列按当前口径重述，不能声称严格重建历史当时可知数据。区间涨跌幅、最大回撤、年化波动率保留公式及实际样本区间；年化采用 252 个交易日假设。跨标的日期不一致时不能直接据此给出严格可比排名。

缺失值保留为 null，不当成零。缺失时点的数值不作为核验事实或模型推断依据；明显滞后或未覆盖区间的数据标记为待核对。来源冲突的自动交叉仲裁尚未实现，本版每项任务使用一个明确来源，不宣称多源交叉验证。

## 项目结构

| 路径                                                | 职责                                             |
| --------------------------------------------------- | ------------------------------------------------ |
| `app/page.tsx`、`app/globals.css`                   | 研究工作台、动态任务、证据面板、图表与报告       |
| `app/api/research/route.ts`                         | 身份与同源校验、研究及记忆操作                   |
| `lib/research/planner.ts`                           | 目标解析、模型计划与规则降级                     |
| `lib/research/engine.ts`                            | 状态机、审批、预算、压缩、报告                   |
| `lib/research/tools.ts`                             | 工具注册、数据适配、质量校验、确定性指标         |
| `lib/research/model-settings.ts`、`model-budget.ts` | 模型来源、个人密钥校验、固定供应商地址与原子额度 |
| `lib/research/workspace.ts`                         | 匿名工作台凭据生成与校验，不依赖账号             |
| `lib/integrations/ifind.ts` | iFinD MCP 握手、JSON/SSE、工具发现与会话清理 |
| `lib/research/store.ts`                             | D1 持久化、租约、进度与检查点                    |
| `db/schema.ts`、`drizzle/`                          | 数据模型与生产迁移                               |
| `tests/`                                            | 核心、API、真实行情及浏览器验收                  |

数据按服务端校验的匿名工作台隔离；API 端检查会话有效期与研究归属，不读取平台用户身份。输入、模型输出和工具返回均视为不可信内容。没有交易工具、持仓写入、外部邮件发送或自动买卖能力。
